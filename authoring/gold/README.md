# The gold set

Sixteen hand-made example microgames, each paired with the request a person would type to get it.
They are what we want Muse to make. Studio puts the two closest to each request into Muse's prompt
(`expander/gold.mjs`, used by `MicrogameComposer`), and `pairs.jsonl` holds them as chat-format
training pairs for few-shot use on a server, or for fine-tuning if that becomes possible.

| Group | Games |
|---|---|
| Stories you play (`story.json`) | The Stormglass Affair (wizard-school mystery, 7 endings), Last Run of the Magpie (smuggler in a galactic rebellion), The Hostess Knows (prep-school gossip scandal), The Saffron Egg Job (heist) |
| Brain-rot and party (`party.json`) | Aura Farm, NPC or Main Character?, Goblin Mode: Snack Run, Rizz or Flop |
| Arcade (`arcade.json`) | Moonbroom Derby, Rift Run, Rooftop Courier, Cake Tower |
| Quizzes and social (`social.json`) | Which House Claims You?, Who Posted It?, Static from the Driftwood Fleet, Pillow Fort Night |

Every game is original. Several are homages to well-known genres (a magic school, a space
rebellion, a gossip-driven prep school), but none uses a franchise's names, characters, places,
spells, ships or quotes. Muse's prompt asks for the same when a request names a franchise.

## What makes them gold

Each one has original SVG art for every role, a sound set, built-in game feel (particles, pops,
shake, haptics), a difficulty curve, and real ways to win and lose. Each validates with no errors
and passes the five-bot gate. Each entry also says why it works and which real Muse mistakes it
avoids. Those mistakes come from Karthik's real-Muse run: invented feedback syntax, games that
can't be lost, quizzes over in 5 seconds, out-of-range params.

## Files

- `story.json`, `party.json`, `arcade.json`, `social.json`: the entries (`id`, `file`, `request`,
  `brief`, `genre`, `fragments_used`, `why_its_good`, `pitfalls_avoided`). Edit these.
- `index.json` and `pairs.jsonl`: generated by `node authoring/tools/build-gold.mjs` (`--check`
  verifies). The games themselves are `authoring/games/gold_*.authoring.json`.

After changing any of them, rebuild the derived files and the Studio bundle:

```sh
node authoring/tools/build-gold.mjs
node authoring/tools/make-studio-bundle.mjs
node authoring/playtest/run.mjs authoring/games/gold_*.authoring.json   # every gold game must pass
```

## Adding a game

Write the manifest in `authoring/games/gold_<id>.authoring.json`, add its entry to the right group
file with a realistic `request`, and check it: `node authoring/expander/cli.mjs <file>` (no errors),
the gate above, and a look at it in the browser or with `tools/runtime-tests/microgame-chrome.mjs`
(it accepts a wrapped manifest file). Keep it original.
