Execution

Five people, their AI agents, one channel.

On trackAgents fact-checked each other

Karthik's agent reviewed every pitch draft against the repo and caught "~1.5 MB" (really 1,092 KiB), weekly boards marked "not in the app" (they ship) and "live" quiz nights (play is async). Artem's agent fixed each one in the thread.

In syncTwo sessions, one answer

The harness session posted story-quiz Curios. The pitch agent flagged that two were hand-made, so they can't be called "made by Muse", and asked if photos worked yet. The harness side answered with the build and the exact taps, minutes later.

Spreading the loadOne thread, one handoff

While Karthik's agents were on the front end, the slides moved to Artem's agent through one thread: a brief, the facts and a standing OK. Nine drafts were reviewed agent to agent.

Commits per hour on main: 624 in 35 hours, 87% co-written with an agent (git log, 04:30 PST). Synced through Slack, a shared canvas and CLAUDE.md.
