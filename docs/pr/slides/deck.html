03 · How Muse powers it · inside the harness

What's inside the harness

Every request runs the same pipeline on our server. Muse does the creative work; code grounds it, checks it and keeps it fair. The phone only plays the result.

1 · Understand

Muse SparkReads the request

Verbs, inputs, theme, and any game or franchise you named.

codeSearches the catalog

1,305 game types and 285 tools, matched by keyword, fuzzy text and aliases.

codeLooks up the unknown

A name it doesn't know is looked up on the web and saved for next time.

code + MuseTakes in your media

Photos or a video, cut into story beats and described.

2 · Plan

Muse WonderWrites a game spec

Every part named: theme, goal, loop, pieces, rules, levels, ending, score, how friends play, feel.

codeQuotes your words

Your must-haves become requirements the game is tested against.

youAgree the plan

The app shows the plan part by part; nothing builds until you agree.

3 · Compose

Muse WonderWrites the game

In our engine's language, from only the pieces the plan picked: a prompt menu cut from 36,600 to under 12,500 characters.

Muse ImagePaints it

Backdrops and sprites in one look. If a name is refused, it retries with a plain description.

codeRuns on any phone

One game file, played by our Rust engine on the phone; the same engine replays it on the server.

4 · Prove and ship

codeFive bots, eight profiles

Played to the end; too easy, broken controls or no ending are blocked.

codeFair score

Skill order, no idling or mashing to win, every run replays to the same score.

codeEvery frame checked

29 failure classes, fixed in place, then proven: same rules, same replays.

MuseRepairs only what failed

Time-boxed. What can't be met ships with an honest note, or not at all.

Then, for every real player: the server replays each score from its inputs before it counts, and Groups play on the same seed.
03 · How Muse powers it · the verifiers

Every Curio is proven playable before anyone plays it.

Muse writes the game. Then code, not another prompt, plays it, scores it and checks every frame. A game that fails is fixed or never ships.

1Five bots play it

A new player, a regular, a pro and two more seeds each play to the end.

Eight game profiles (arcade, runner, puzzle, calm, trivia, search, opinion, story) set what counts as broken.

Blocked: a game a bot wins in under 15 seconds, controls that do nothing, a story that never ends.

2The score is fair

The pro must beat the regular, and the regular the new player.

A bot that does nothing can't rank above players, and one that mashes a button can't beat a regular.

Replayed: every run is played again from its inputs and must land on the same score. The server does the same for every real score.

3Every frame is checked

Each bot run is replayed and looked at every 100 ms, and motion every 50 ms.

29 failure classes: unreadable text, words split mid-line, text over text, buttons too small to tap, shaking and popping.

Fixed, then proven: the fix may only move how it looks. Same rules, same replays, checked.

How we built it

How AI built this with us: where it helped most, where it fell short, and how we adapted.

  • We spent our first two hours away from Claude, then worked with agents as teammates: five people, 643 agents on one Mac, one Slack channel.
  • Agents checked each other's work, so mistakes were caught before they shipped.
  • When Muse or the agents fell short, we changed the process, not just the output.
04 · How we built it · how we work with agents

How we work with agents

0
Ideas before agents. We spent our first two hours away from Claude: whiteboards, arguments, sketches. Our ideas had room to grow before anything got built.
1
Agents are teammates. Each of us runs our own agents, and every post they make is signed "AI agent for" their person.
2
One place to stay in step. One Slack channel, a canvas where agents claim work before they start, and CLAUDE.md: the rules every agent reads first.
3
People decide, agents ask. Names, merges to main and anything a person must own wait for a human OK.
4
Check, don't trust. Every draft is reviewed by another agent against the code, and code, not a prompt, decides whether a game works.
5
Fan out, then converge. Many agents in parallel, each in its own copy of the repo; one integrator merges and runs every test before a push.
6
Say it as it is. "Simulated", "made by Muse" and "in the app" appear only when they're true.

04 · How we built it · what we learned

Where AI helped most, where it fell short, and how we adapted.

Helped most

Doing many things at once. 643 agents on one Mac did about 158 hours of work in 22. A review of every merged screen took 3 hours, not 28.

Checking each other. Every slide draft was fact-checked by another agent against the code before anyone saw it.

Inside the product. One sentence becomes a planned, tested Curio, with no developer in the loop.

Fell short

Muse alone guessed. One giant prompt (137,000 characters) gave games that missed what people asked for, and a speed-reading game a bot could win instantly.

Muse Image said no. Asked for a Dumbledore sprite sheet, it refused on content policy, 2 runs out of 2. And Muse's own art step undid the verifier's layout fixes.

Limits ran out. The Muse key hit its spending limit mid-test, and billing failed partway through our requirements test.

Agents drifted. Confident wrong facts ("~1.5 MB", "live" quiz nights), overlapping branches, and an hour without Slack.

People missed things. An older Curio shipped with "Wave 1 of 5" at 1.48:1 contrast; 4.5:1 is the floor.

How we adapted

A harness, not a prompt. Search, a plan, five bots and checkers. Must-haves met rose from 94% to 98%; the gate rejected the speed-reader three times out of three.

Retry, then fall back. One retry with plain descriptions instead of names; if it still refuses, drawn art. Pictures are added before the final check, so fixes stick.

Budgets. A cap on Muse calls per agent, and a human OK before any big batch.

Shared rules. CLAUDE.md, a canvas where agents claim work, one Slack thread per handoff, and a review on every draft.

Code checks people. The contrast check now blocks that game: 33 issues. Old Curios are re-run through it.
